# 🚀 Featured Research Projects

## 🦾 Knowledge-driven Fine-grained 3D Reconstruction for Complex Structural Components

**Research Project | Chinese Academy of Sciences**

This project focuses on fine-grained 3D reconstruction of complex structural components for robotic welding and cutting applications in flexible manufacturing.

By utilizing multi-modal sensing technologies, including point clouds, RGB images, stereo vision, and laser scanning, the project aims to build accurate 3D models of industrial components and provide reliable data support for intelligent robotic manufacturing.

---

## 🚦 Digital Infrastructure Modeling for Complex Urban Intersections Using Panoramic Dynamic Images

**Research Project | Chinese Academy of Sciences**

This project focuses on developing a digital mapping foundation for intelligent transportation systems.

By analyzing panoramic dynamic images and multi-sensor data, the project builds accurate digital representations of complex urban intersections to support future applications such as traffic signal optimization and intelligent transportation management.

---

## 🏙️ Urban Renewal Planning Simulation and Decision Support Platform

**Research Project | Chinese Academy of Sciences**

This project aims to develop an intelligent simulation platform for urban renewal planning.

By combining artificial intelligence models, population data analysis, and urban simulation technologies, the platform predicts residential allocation strategies and supports data-driven decision-making for sustainable urban development.
